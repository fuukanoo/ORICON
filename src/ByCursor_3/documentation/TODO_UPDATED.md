# CISF (Cross-Industry Synergy Finder) プロジェクト TODO

## 🎯 **プロジェクト目標**
オリコン満足度調査データから業界横断的なブランドコラボレーション可能性を発見するAIシステム

## ⚠️ **重要な発見：データ構造の制約**

### **調査結果**
- **全業種で全ブランド横断評価データは存在しない**
- 各回答者は**主要利用ブランド1つのみ**について詳細評価
- **subscription_movie例**: 35ブランドあるが、Q1は選択した1ブランドのみの満足度
- **tenshoku_scout_service例**: Q2_1〜Q2_11は11項目の評価（11ブランドではない）

### **データ構造パターン**
1. **利用状況**: SQ6_1[1-35] (0/1) - 複数ブランド利用状況
2. **主要選択**: SQ6_2 (1-35) - 最もよく利用するブランド1つ
3. **満足度評価**: Q1, Q2系列 - 選択したブランドのみの詳細評価

## 🔧 **修正されたアプローチ**

### **オプション1: 主要利用ブランド満足度分析** ⭐ **推奨**
- 各回答者の主要利用ブランドの満足度のみ使用
- **メリット**: 実データベース、統計的に有意
- **デメリット**: ブランド間直接比較は限定的

### **オプション2: 利用状況ベース推定**
- SQ6_1の利用状況(0/1)から疑似満足度を推定
- **メリット**: 全ブランド比較可能
- **デメリット**: 推定ベース、精度に課題

### **オプション3: データ収集改善提案**
- 全ブランド評価を含む新調査設計の提案
- **長期的解決策**
