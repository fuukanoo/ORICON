# CISF（Cross-Industry Synergy Finder）実装進捗管理

## プロジェクト概要

**目標**: 満足度アンケートデータから「エントロピーが下がり」「平均スコアが上がる」組み合わせを発見し、ブランド間コラボの新提案を自動生成する。

**PoC成功条件**: 
- コラボ候補5件以上を提示し、いずれも Δμ>0 かつ ΔH>0
- 過去のコラボを用いた Precision@5 が 0.3 以上
